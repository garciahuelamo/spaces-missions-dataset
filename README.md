# Global Space Exploration Analysis Project

## Overview
This project analyzes the **Global Space Exploration Dataset (2000-2025)** 🚀 to uncover trends, patterns, and insights in global space exploration activities over the past two and a half decades.

## Dataset
- **Source**: [Global Space Exploration Dataset (2000-2025) 🚀](https://www.kaggle.com/datasets/atharvasoundankar/global-space-exploration-dataset-2000-2025)
- **Time Period**: 2000-2025
- **Focus**: Global space missions, launches, and exploration initiatives

## Project Goals
- Explore space exploration trends across different countries and organizations
- Analyze mission types, success rates, and frequency over time
- Identify key players and contributors to global space exploration
- Visualize patterns in space exploration data

## Technologies Used
- Python
- Pandas & NumPy for data manipulation
- Matplotlib & Seaborn for visualization
- Jupyter Notebook for analysis

## Folders Overview

### data/
Contains the Global Space Exploration Dataset (2000-2025) with information about:
- Space missions and launches
- Mission types and classifications
- Success/failure rates
- Countries and organizations involved
- Temporal data spanning 2000-2025

### scripts/
Contains Python scripts for:
- Data loading and preprocessing
- Exploratory Data Analysis (EDA)
- Data visualization
- Statistical analysis
- Trend analysis and pattern identification
